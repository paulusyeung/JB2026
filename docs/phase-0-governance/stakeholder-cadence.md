# Stakeholder Review Cadence

## Cadence by Phase
- Weekly architecture board: platform, API, data, UI, QA, DevOps leads.
- Bi-weekly migration steering: technical leads and product owner.
- Gate reviews: ad hoc at gate completion (A/B/C), formal sign-off required.

## Decision Input Loop
1. Workstream owners submit artifact updates and open risks.
2. Architecture board reviews technical implications and dependencies.
3. Steering review resolves escalations and approves gate progression.
4. Decisions and rationale are recorded in migration decision log.

## Required Outputs per Review
- Updated risks and mitigations.
- Dependency/license deltas.
- Benchmarking and quality trend updates.
- Gate readiness status and blockers.
