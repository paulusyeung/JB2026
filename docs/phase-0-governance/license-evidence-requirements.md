# License Evidence Requirements for Keep CE Decisions

## Required Evidence
- Official vendor license text or terms URL.
- Explicit statement proving redistribution/public open-source compatibility.
- Version-specific terms if licensing differs by edition/version.
- Internal reviewer sign-off (platform/compliance owner).

## Decision Outcomes
- Approve `Keep CE` only when evidence is complete and unambiguous.
- If ambiguous, mark dependency as blocked for Gate B.
- If incompatible, assign replacement strategy.
