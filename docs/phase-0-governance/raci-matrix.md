# RACI Matrix - Phase 0 Governance

## Roles
- Platform Lead (PL)
- API Lead (AL)
- Data Lead (DL)
- UI Lead (UL)
- QA and Performance Lead (QL)
- DevOps Lead (OL)
- Product Owner (PO)

## Responsibilities

| Work Item | PL | AL | DL | UL | QL | OL | PO |
|---|---|---|---|---|---|---|---|
| Migration charter approval | A | C | C | C | C | C | R |
| Gate criteria definition | A | C | C | C | C | C | C |
| Dependency and license matrix | R | C | C | C | C | C | I |
| Out-of-scope registry | A | C | C | C | C | I | R |
| Benchmarking baseline and checkpoints | C | C | C | C | A | R | I |
| Governance review package | A | C | C | C | C | C | I |
| Phase 0 sign-off | A | C | C | C | C | C | R |

Legend: R = Responsible, A = Accountable, C = Consulted, I = Informed
